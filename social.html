家鄉在哪裡 p.10–11

我們出生、成長，或是長期生活的地方，都是我們的家鄉，所以家鄉可能不只一個。

  • 臺南出生、長大 → 家鄉在臺南市，位在臺灣南部
  • 嘉義出生、從小住新北市 → 覺得家鄉在新北市，位在臺灣北部
  • 花蓮縣位在臺灣東部，有高大山脈，也有廣闊海洋
  • 現在住新竹市（地圖上看起來非常小）、小學前住臺中市 → 兩個都是家鄉
易錯：「家鄉只有一個，就是出生的地方」是錯的。長期生活的地方也算家鄉。

地圖的四個要素 p.14

地形的種類 p.20–21

地形是指地表高低起伏的型態。可以用實地觀察、空拍照片、閱讀地圖來認識。

地形特徵（關鍵字）課本例子
平原平坦廣闊宜蘭平原
盆地四周高，中間低平埔里盆地（南投）
台地頂部平坦，邊緣以陡坡和低地相接大肚台地（臺中）
丘陵高度不超過 1000 公尺、坡度較平緩苗栗丘陵
山地高聳，高度在 1000 公尺以上中央山脈
易錯：盆地和台地最容易搞混。盆地像臉盆，四周高、中間低；台地像桌子，上面平、旁邊是陡坡。丘陵和山地用 1000 公尺分開。

地形與生活 p.22–23

平原、盆地、台地（較平坦）→ 有利於種植作物、建築房屋、交通建設 → 形成農田遍布的農村，或高樓林立的都市。靠海的平原 → 可能看到一池池魚塭的漁村。

丘陵、山地（起伏較大）→ 居民活動受到限制 → 多選在坡度較平緩的山坡地開闢茶園、果園。

地形影響居民的生活方式；居民的活動也改變了地表的景觀與樣貌。

地方地形居民生活
臺東縣 池上鄉平原一大片稻田
臺北市 信義區盆地四周山圍繞、地形平坦、交通便利，熱鬧的大都市
屏東縣 枋寮鄉平原（靠海岸）很多魚塭
新北市 石碇區丘陵氣候適宜、排水良好 → 種茶、製茶
臺中市 和平區山地大多以種植水果為生（甜柿）
易錯：臺北市信義區是盆地，不是平原；石碇種茶是丘陵，不是山地。

家鄉的氣候 p.24–25

氣候是指一個地區長時間的天氣平均狀況。認識氣候，可以從氣溫圖和雨量圖開始。

地方特色圖上的數字
宜蘭夏熱冬冷7月 28.9°C ／ 1月 16.6°C
屏東 恆春四季氣溫高7月 28.7°C ／ 1月 21.1°C
基隆四季多雨只有 7月 119.5 毫米低於 200
高雄夏季多雨、冬季少雨6–8月都超過 300 毫米（8月最多 512.4）
2月最少，只有 17.7 毫米
易錯：宜蘭和恆春的 7 月氣溫差不多（28.9 和 28.7），真正的差別在冬天：宜蘭 1 月只有 16.6°C，恆春還有 21.1°C。所以判斷「四季氣溫高」要看最冷的月份。

氣候與居民的生活 p.26

居民會根據不同的氣候，選擇不同的建材、種植適合的作物、從事多樣化的休閒活動，發展出合適的生活方式。

  • 建材：新北市瑞芳區九份常常下雨 → 屋頂用瀝青製成的油毛氈，黑色屋頂是很好的防雨建材
  • 作物：澎湖七美鄉雨下得比較少 → 種需水較少的耐旱作物花生
  • 休閒活動：屏東天氣炎熱 → 夏天到海邊堆沙堡、戲水；高雄夏天高溫 → 待在涼快的地方吃冰
易錯：九份是多雨（所以防雨屋頂），澎湖是少雨（所以種耐旱的花生）。兩個剛好相反，不要對調。

家鄉的水資源 p.27

河川、湖泊、地下水、海洋等，都是家鄉重要的水資源。

  • 河川的水量會因季節的降雨量而不同
  • 例：中部的濁水溪夏季雨量多，河水量也多；冬季雨量少，部分河床裸露
  • 河水多流入海洋，或滲入地下成為地下水
易錯：濁水溪是夏季水多、冬季河床裸露，原因是降雨量不同，不是氣溫。

水資源與居民的生活 p.28–29

水資源與家鄉居民的生活息息相關，提供居民日常所需。

  • 政府在部分河川的中、上游建有水庫，功能：供給民生與工業用水、灌溉、水力發電
  • 休閒活動：在河川、湖泊、海洋划船、騎自行車環湖、浮潛
  • 課本圖中的水資源：水庫、湖泊、水圳、埤塘、河川、海洋（還有養魚的魚塭）
  • 不當使用可能造成汙染（例：河川變紅色、味道難聞）。保護水資源是大家的責任，要避免汙染、珍惜並愛護水資源
易錯：水庫建在河川的中、上游，不是下游出海口。保護水資源是「大家」的責任，不是只有政府。

小小探究家：何時旅遊比較好？ p.30–31

四個步驟：1 發現問題 → 2 蒐集資料 → 3 整理分析 → 4 行動省思

原住民族的傳統住屋 p.34–35

原住民族以就地取材的方式，使用石板、木頭、竹子、茅草等材料搭建傳統住屋，為了適應自然環境，發展出獨具特色的建築形式。

住屋族群・地點材料特色
石板屋排灣族（屏東縣瑪家鄉 舊排灣部落）石板冬暖夏涼
地下屋雅美族（達悟族）（臺東縣蘭嶼鄉 野銀部落）木頭、石頭比較低矮的半地下式住屋，可以躲避強風
傳統住屋泰雅族（宜蘭縣蘇澳鎮 武荖坑風景區）木頭、竹子供遊客認識傳統建築技術及工藝之美

會呼吸的房子：石板屋

  • 大大小小的石板交錯堆疊，構築成堅固的石板屋
  • 石板厚，夏天隔熱、冬天保暖 →「冬暖夏涼」
  • 在屋裡升火煮食、取暖，煙可讓木頭防腐、防蟲，並順著石板之間的縫隙往外飄 →「會呼吸的房子」
  • 例：排灣族與魯凱族的石板屋
  • 世界建築文物保護基金會（WMF）把屏東縣霧臺鄉魯凱族石板屋聚落（舊好茶部落）列入文物守護計畫名單
易錯：「會呼吸」是因為煙從石板縫隙飄出去，不是因為有窗戶。地下屋是蘭嶼雅美族（達悟族），為了躲強風，不是為了躲雨或保暖。

漢人的傳統住屋 p.36–39

漢人的傳統住屋也受到自然環境影響，大多就地取材，用竹子、木頭或土石建造；有些用人工燒製的磚瓦建造。

住屋怎麼蓋課本例子
竹管仔厝用竹子當骨架，再敷上泥土雲林縣麥寮鄉
土埆厝用石塊作基礎，再用稻稈、泥土和水做成土磚新北市深坑區
磚瓦住屋人工燒製的磚瓦桃園市楊梅區 黃家古厝

有些家族人口眾多或家境較富裕，會直接興建三合院。

走進三合院：鳥瞰手繪圖

想像你是一隻小鳥，從天空往下看奶奶家的三合院。圖上的號碼對照下面的說明。

  1. 正廳：在正身的正中間，供奉神明和祖先牌位，用來祭拜和接待客人。
  2. 稻埕：三合院中間的大空地。曬穀、小孩玩遊戲、乘涼聊天、彈唱戲曲、祭拜請客，是多用途的地方。
  3. 水池：洗東西、養魚；發生火災時可以滅火。
  4. 果樹：可以採水果、撿柴火。
  5. 堆肥場：枯枝落葉加上人和禽畜的糞尿做成堆肥，讓土地肥沃。
  6. 竹林：可以拿來編器物、修房子，還能防風、防盜。

三合院的左右：要從正廳「面朝外」看

看圖中站在正廳前的小人：他背對正廳、面朝稻埕。他的左手邊，就是三合院的左邊。

在鳥瞰圖上，「左護龍」反而畫在右邊！因為我們是從外面看進去，小人是從裡面看出來，方向剛好相反。

傳統觀念以左為尊，房間依「左大右小」分配，所以左護龍是大邊、右護龍是小邊。

易錯：單伸手是一邊護龍，三合院是兩邊護龍。三合院的左右要「面朝外」看，和你從大門走進去看到的左右相反。

傳統住屋的改變 p.40–41

原因：工商業的發展、生活方式的轉變、建築材料的革新 → 許多傳統住屋拆除後，改為鋼筋混凝土的樓房。

少數留存的傳統住屋：部分仍有居民居住；有些改建為特色餐廳（例：臺中市烏日區三合院改成咖啡廳）。

為了保存先民的智慧結晶，政府和民間積極推動維護與保存：

  • 列為古蹟
  • 規畫為聚落保存區（例：澎湖縣西嶼鄉二崁村，被選定為文化聚落保存區）
  • 結合當地特色成為觀光景點

其他例子：屏東縣春日鄉排灣族七佳部落（保存完整的石板屋聚落）、苗栗縣頭份市蘆竹湳聚落。

器物與生活 p.42–45

早期居民從自然環境中就地取材，製作各種日常生活器物，讓生活更便利。

誰器物材料用途
原住民族魚筌竹子、藤捕捉魚蝦
原住民族木杵木頭搗製食物
原住民族月桃葉等植物葉子包裹食物
漢人土灶泥土煮菜、蒸粿
漢人粽葉等植物葉子包裝粿、粽子
漢人菜櫥、水桶、砧板木材日常使用

魚筌的智慧（阿美族）

  • 形狀像漏斗，魚游進去後不容易再游出來
  • 放在溪裡時，旁邊要找石頭固定好
  • 旁邊有空隙，小魚可以從縫隙游出去繼續長大 → 不讓魚被捕光，魚群生生不息

灶的物盡其用

  • 用木柴燒火，增加或減少木柴來控制火力大小
  • 灰燼的餘溫可以把地瓜悶熟；冷卻後的灰燼可以當菜園的肥料
  • 傳統器物的原料多來自大自然，用過的廢棄物最後也回歸大自然
易錯：魚筌留縫隙不是做壞了，是為了讓小魚逃走、長大，魚才不會被捕光。灶的灰燼是拿來當肥料，不是丟掉。

生活器物的現代風貌 p.46–47

  • 科技進步，玻璃、金屬、塑膠的器物更普遍
  • 塑膠器物輕便又便宜，取代了傳統竹、木製造的器物
  • 但塑膠不易在自然環境中分解，丟棄後變成難以處理的垃圾
  • 響應減塑運動：選擇對環境友善、能重複使用的器物（例：用不鏽鋼吸管，或直接喝）
  • 淨灘撿到的海洋廢棄物以塑膠器物為多數，第一名是寶特瓶，第二名是塑膠瓶蓋（民國 112 年）

小小探究家：器物大不同 p.48–51

步驟一樣：發現問題 → 蒐集資料 → 整理分析 → 行動省思

  • 早期器物例子：斗笠、桌罩、背簍

漢人的傳統信仰與生活 p.56–57

漢人常常興建廟宇祭拜神明，以祈求平安與豐收。

神明別稱保佑什麼
土地公福德正神守護農田、村莊，保佑作物豐收。土地公廟是臺灣最常見的廟宇
媽祖天上聖母保佑航海平安。每年的媽祖繞境吸引各地信徒參加

家鄉的廟宇是當地的信仰中心；廟前廣場是大家休閒聚會的地方。廟宇會舉辦儀式、祭典和慶祝活動，也能藉此聯絡家鄉居民的感情。

易錯：「福德正神」是土地公，「天上聖母」是媽祖。土地公管農田豐收，媽祖管航海平安。

信仰與現代生活 p.58–59

  • 居民有不同的信仰活動：燒香拜拜、參加廟會慶典、到教會做禮拜等
  • 現代生活觀念轉變，信仰活動也會改變：為了響應環保，有些廟宇減少燒香，改用雙手合掌代替
  • 大多數的信仰都在鼓勵人們修身養性、行善助人、勇敢克服困難，具有安定人心、促進社會祥和的功能
  • 有些居民受信仰影響，成為宗教團體的志工，服務眾人
  • 面對不同的信仰，我們都應該尊重與包容（例：同學星期天要做禮拜，就改約星期六打球）
易錯：廟宇減少燒香的原因是環保，不是不虔誠。面對別人的信仰要尊重，不能要求對方放棄自己的信仰活動。

社會充電站：高遶教堂 p.60–61

原住民族傳統普遍信仰祖靈或神靈。因為外來文化的傳入，有些原住民族也信仰基督教或天主教，尋求心靈的慰藉。

地點：桃園市復興區 高遶部落（在羅馬公路上）。「高遶」（Qoyaw）在泰雅族語中指長枝竹，穩固不易斷，是很好的材料。

時間教堂的材料為什麼改
民國 37 年在民宅內聚會 → 就地取材，用竹子建教堂信徒增多，需要較寬敞的場地
土磚（土埆教堂）竹子風吹日曬容易毀損

居民因為有虔誠的信仰支持，堅持又無私的付出，遇到困難也不放棄，教堂終於重現，成為信徒聚會、禱告的場所。

老街與生活：三峽老街 p.62–63

從老街的建築外觀、廟宇、販賣的商品，可以發現老街的特色。

  • 建築外觀：許多看起來很像的紅磚房子，有拱形的騎樓和華麗的立面
  • 廟宇：三峽祖師廟，已有兩百多年的歷史
  • 特色產品：金牛角麵包、藍染（可以參加染布體驗）

老街的發展 p.64–65

廟宇是人們經常聚集的地方 → 吸引商人、小販到廟宇附近買賣 → 形成市集或商店街 → 部分演變成現在的老街。

市集：在固定時間、地點，進行貨物買賣的場所。

老街的街屋

  • 店鋪在道路兩旁，店面朝向街道
  • 設有騎樓，供顧客、行人遮陽避雨（例：金門縣金城鎮 金城老街，至今仍保有完整的騎樓）
  • 店鋪的後方或樓上是商家起居作息的場所 → 店家兼顧工作與生活
易錯：老街是從廟宇附近的市集發展來的，不是從火車站。騎樓的功能是遮陽避雨；商家住在店鋪的後方或樓上。

老街的轉變 p.66

到了現代，老街也有了轉變。老街保留了過去先民生活的記憶，是家鄉重要的文化特色。

轉變例子說明
沒落、人潮減少臺南市 橋南老街早期是鹽水區最熱鬧的街道之一，後來港口淤積而沒落，轉為寧靜的住宅區
傳統及新興商店並存臺中市 南屯老街早期有許多製造、買賣農具的店鋪；現在老店和新興商店都有，是居民平日購物的商店街
經過規畫與維護，保留原始風貌彰化縣 鹿港老街保留許多早期閩南式建築，吸引國內外遊客觀光
易錯：三條老街配三種轉變：橋南＝沒落（港口淤積）、南屯＝新舊並存（農具店）、鹿港＝保留原貌（閩南式建築）。

傳統生活作息的依據 p.74–77

原住民族配合季節與氣候變化安排農耕、狩獵、祭祀，並用口耳相傳或畫圖把活動的時間和內容流傳下來。

  • 口耳相傳：魯凱族打獵的季節是冬天，因為天氣冷，獵物比較容易保存
  • 畫圖：布農族的木刻畫曆，用刀子在木板上刻圖形符號，記載全年要做的事（農耕、狩獵、祭典）。除了提醒族人生活要規律，也能傳承知識與文化

漢人的農民曆

漢人的祖先觀察自然的變化發明農曆，用來安排生活作息、工作及節慶，形成農民曆。

農民曆上有：國曆的月分、日期星期、農曆的月日、適合栽種的作物、可以捕撈的魚類、適宜或不適宜（宜／忌）從事的活動。

農民曆上的種植和捕撈時期來自傳統經驗，隨著科技發展、技術提升，現在不一定相同。

現代有人仍參考農民曆挑日子結婚、搬家（入宅）；也有人挑有意義的日子（例：5 月 20 日「我愛你」），或利用週末假日。

易錯：木刻畫曆是布農族，冬天打獵的是魯凱族。農民曆是漢人觀察自然變化發明的。

現代的生活作息 p.78–79

  • 我們現在使用的陽曆也稱為國曆
  • 現代作息逐漸脫離配合自然變化的生活步調；生活和工作內容比過去複雜許多 → 改用陽曆與星期制，有了工作日與休息日的區別
  • 科技進步，生活較不受時間與地點的限制，可依個人需求彈性安排學習、工作、消費及娛樂
  • 政府實施週休二日後，人們有更多時間安排休閒活動

原住民族的祭典 p.80–81

為了祈求農事或漁獵順利 → 播種祭、招魚祭；慶祝作物豐收 → 豐年祭、感恩祭；傳承狩獵技巧 → 大獵祭。

族群祭典時間重點
邵族播種祭國曆 4 月春季舉行，祈求作物順利成長、豐收。讓小朋友第一個播種，代表作物能健康成長
阿美族豐年祭國曆 7–9 月祭典禮俗與傳統歌舞，感謝上天的恩賜。外人沒有受到邀請，不可隨意參與

漢人的節慶 p.82–84

漢人配合季節進行農事，並利用農閒時間舉辦節慶活動。農閒時間：農民完成每一階段農事後的閒暇時間。

尊重族群的不同祭典與節慶 p.85

傳統祭典或節慶多含有感謝天地、敬神祭祖、家人團圓等意義。參與不同活動可以：體會先民的智慧、凝聚家族的向心力、豐富居民生活、促進不同族群間的互動與理解。

例：賽夏族祖靈祭（竹籤串豬肉、裝酒的竹杯、糯米糕）與漢人祭祖，都在祭拜祖先，只是方式、場所和供品不同。敬畏祖先、感恩與祈福的心意是一樣的，都值得了解與尊重。

這是哪一種節日？三步驟判斷

  1. 是祖先流傳下來的嗎？
    是 → 漢人的傳統節慶（利用農閒舉辦）或原住民族的祭典（配合播種、收割、狩獵）。
  2. 不是？那就是現代節日，再問：這個節日是為了誰、為了什麼？
  3. 五種現代節日
    • 人生不同階段：兒童節、青年節、母親節、父親節 → 關懷、期許、敬愛
    • 各行各業：勞動節、警察節、教師節 → 感謝他們的付出
    • 國家重要：開國紀念日、和平紀念日、國慶日 → 了解國家歷史
    • 外來文化：潑水節、耶誕節 → 國際交流、新住民帶來
    • 與議題相關：世界地球日、世界閱讀日 → 重視環保、閱讀
易錯：兒童節是現代節日，不是傳統節慶；清明節是傳統節慶，卻用國曆。4 月最熱鬧：兒童節、清明節、播種祭、潑水節、地球日、閱讀日都在 4 月。

介紹家鄉有方法 p.98–107

例子：臺東縣國小四年甲班要到臺中市做校際交流，向對方介紹自己的家鄉。

  • 步驟 1 發現問題：想一想要怎麼介紹家鄉
  • 步驟 2 蒐集資料：上網查資料、圖書館查資料、訪問居民（訪問居民可以獲得多元的資料）
  • 步驟 3 整理分析：選主題（著名美食、地形、氣候、位置、特殊節慶、景點…），再選介紹方式（口頭報告、製作海報、製作小書）
  • 步驟 4 行動省思：決定製作家鄉小書，因為小書可以呈現多元豐富的資料，又方便攜帶（只有口頭報告怕介紹不清楚，海報太大張不好攜帶）
